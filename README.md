# hr-policy-bot

# HR Policy Bot 🤖

An AI-powered HR Policy Assistant built using Streamlit and LLMs.
This application helps users quickly query and understand HR policies.

---

## 🚀 Features

* Ask questions related to HR policies
* AI-powered responses using LLM
* Simple and interactive UI with Streamlit

---

## 🛠️ Tech Stack

* Python
* Streamlit
* LangChain
* OpenAI / LLM APIs

---

## 📂 Project Structure

```
├── agent.py
├── capstone_streamlit.py   # Main Streamlit app
├── requirements.txt
├── README.md
├── LICENSE
```

---

## ⚙️ Installation

1. Clone the repository:

```
git clone https://github.com/Sayantani630/hr-policy-bot.git
cd hr-policy-bot
```

2. Install dependencies:

```
pip install -r requirements.txt
```

3. Run the app:

```
streamlit run capstone_streamlit.py
```

---

## 🔐 Environment Variables

Create a `.env` file or use Streamlit secrets:

```
API_KEY=your_api_key_here
```
